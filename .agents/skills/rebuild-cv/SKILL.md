---
name: rebuild-cv
description: Edit, tailor, rebuild, and validate a local RenderCV resume template. Use for content or layout changes, not submitting applications.
---
Read `AGENTS.md`, `README.md`, and `REVIEW.md` before editing. Treat owner
confirmations and locally supplied source documents as evidence; never infer or
invent personal facts.

For a targeted resume, map each requested requirement to owner-confirmed
evidence. Keep unsupported requirements as review questions. Use the master
inventory for complete content and a variant for a focused selection.

Run the local tests and build command in `AGENTS.md`. Inspect every generated
PNG and read the QA report and extracted text. Warn explicitly when tools are
missing, rendering was not executed, or visual inspection was not performed.
The checker is not an ATS ranking model or factual verification service.

Do not submit, upload, publish, or expose local source files.
